# Website Pages Overview

This website now has separate pages to showcase different components and features to clients.

## Pages Created

### 1. **Home Page** (`/`)
- Landing page with overview of all sections
- Cards linking to each showcase page
- Clean navigation to all areas of the site

### 2. **Buttons Page** (`/buttons`)
- Complete showcase of all button variants (Primary, Secondary, Accent, Pink, Purple, Green)
- All button sizes (Small, Medium, Large)
- Size × Variant matrix showing all combinations
- Interactive demo with clickable buttons

### 3. **Cards Page** (`/cards`)
- Display of all card color variants (White, Primary, Secondary, Accent, Pink, Purple, Green, Blue, Orange)
- Shadow size demonstrations (Small, Medium, Large)
- Rich content cards with icons and buttons
- Nested cards demo showing layered design

### 4. **Components Page** (`/components`)
- Full component library showcase
- Design principles explained
- Complete color palette with hex codes
- Neobrutalism design guidelines

### 5. **Gallery Page** (`/gallery`)
- Art gallery showcase
- Featured artworks from different artists
- Art pieces displayed in colorful cards

### 6. **Menu Page** (`/menu`)
- Café menu with categories
- Coffee, Food, and Dessert sections
- Menu items with prices and descriptions

## Navigation

The navigation bar at the top includes links to all pages:
- **Art × Café** (logo) - Returns to home page
- **Buttons** - Opens buttons showcase
- **Cards** - Opens cards showcase
- **Components** - Opens component library
- **Gallery** - Opens art gallery
- **Menu** - Opens café menu

## Design Features

- **Neobrutalist style** with bold borders and hard shadows
- **Vibrant color palette** throughout all pages
- **Responsive design** that works on mobile and desktop
- **Consistent styling** across all pages
- **Interactive elements** where appropriate

## Technical Details

- Built with Next.js 15.5.7
- Uses App Router architecture
- All pages are statically generated for optimal performance
- Modular CSS with component-specific stylesheets

## Running the Project

```bash
npm install        # Install dependencies
npm run dev       # Start development server
npm run build     # Build for production
```

The website will be available at `http://localhost:3000`
